## Maryland Building Code Updates 2026: The Changes That Matter to Your Commission Check

The Maryland building code updates 2026 took effect after the Maryland Department of Labor's Division of Labor and Industry formally adopted the 2021 International Building Code (IBC), the 2021 International Residential Code (IRC), and the 2021 International Energy Conservation Code (IECC) as the baseline standards for all new construction and major renovations statewide. If you hold a Maryland real estate license and you have not read the implementation guidance published by the Maryland Codes Administration, you are already behind. These are not theoretical changes—they affect how you list properties, what you disclose, and whether your deals actually close.

Maryland follows a statewide minimum code model under Maryland Public Safety Article Title 12, Subtitle 10, meaning local jurisdictions can adopt stricter standards but cannot go below the state floor. Several counties, including Montgomery and Howard, have already layered additional energy performance requirements on top of the state adoption. The practical effect for agents: a property that passes inspection in Allegany County may not pass in Montgomery County, and buyers' inspectors know this.

## What Actually Changed in the 2026 Code Adoption

**The most consequential change for residential transactions is the energy code upgrade from the 2015 IECC to the 2021 IECC.** This shift raises insulation requirements, mandates blower-door testing for all new construction, and imposes stricter air-sealing benchmarks. For agents listing new builds or recently renovated properties, this means asking builders and contractors pointed questions about compliance documentation before marketing a home.

The structural provisions under the IRC also received updates to wind-load and snow-load calculations, particularly relevant for properties in Western Maryland and the coastal zones near Ocean City. Foundation requirements for expansive soils were tightened, and deck construction standards now require specific connection hardware that was previously optional. These are the details that home inspectors will flag—and that buyers' agents will use as negotiation leverage during the inspection period.

Electrical code changes under the 2020 National Electrical Code (NEC), adopted concurrently, now require arc-fault circuit interrupter (AFCI) protection in additional room types and outdoor outlet specifications that older homes won't meet without upgrades. This matters most when sellers have completed DIY renovations without permits.

## How Building Code Updates Intersect with Maryland Disclosure Requirements

Maryland's disclosure framework operates through the Residential Property Disclosure and Disclaimer Statement, governed by Maryland Real Property Article Section 10-702. Sellers can either disclose known conditions or disclaim all representations. But here is where agents get tripped up: even when a seller files a disclaimer, the listing agent's independent knowledge of code violations creates a separate disclosure obligation under COMAR 09.11.02.05 (the Code of Ethics regulation for Maryland licensees).

The relevant form is the **Residential Property Disclosure and Disclaimer Statement (Form)** required under Section 10-702. When a seller chooses the disclosure path, specific questions about structural modifications, additions, and known defects put code compliance squarely in play. If a seller added a bathroom without a permit in 2024, and that bathroom does not meet the plumbing code standards now in force, the seller must disclose this—or the agent who knows about it must ensure it appears somewhere in the transaction file.

**Agents also need to understand how the Maryland Real Estate Commission (MREC) interprets "material fact" in relation to building code status.** Under Business Occupations and Professions Article Section 17-322, a licensee may face discipline for failing to disclose material facts. Unpermitted work that violates current code qualifies. The Commission has issued guidance letters confirming that agents cannot hide behind a seller's disclaimer when they possess actual knowledge.

## Common Mistakes Agents Make with Building Code Compliance

**Mistake One: Assuming "grandfathered" means "no disclosure needed."** A property built in 1985 does not need to meet 2026 code standards—until the owner pulls a permit for renovation. Agents routinely list homes with additions or remodeled kitchens without confirming whether permits were pulled and finaled. When the buyer's inspector identifies unpermitted work, the deal stalls or dies. The listing agent's failure to ask basic questions about permit history becomes the basis for a complaint.

Mistake Two: Failing to check county-specific amendments. Maryland's code is a floor, not a ceiling. An agent working across jurisdiction lines—say, listing in Baltimore County but primarily practicing in Baltimore City—may not realize that Baltimore County adopted additional fire sprinkler requirements for new single-family homes that Baltimore City has not. Citing "state code compliance" without verifying local amendments is sloppy and actionable.

Mistake Three: Relying on the home inspection to catch code issues. Home inspectors in Maryland are governed by Business Occupations and Professions Article Title 16, and their scope of work does not require them to perform code compliance reviews. Inspectors report on observable conditions. They are not code officials. Agents who assume the inspection report serves as a code audit are making a dangerous leap that exposes both the buyer and the transaction to post-closing disputes.

Mistake Four: Not updating listing descriptions after code-related repairs. If a seller cures a code violation during the transaction—say, retrofitting GFCI outlets after an inspection finding—agents sometimes forget to update the MLS remarks or ensure the corrective work is documented with a permit. The buyer's lender may require evidence of permitted repairs, and missing documentation delays closing.

Mistake Five: Ignoring the energy code when marketing "green" features. Agents who advertise homes as "energy efficient" or "green certified" without verifying compliance with the 2021 IECC open themselves to deceptive advertising claims under COMAR 09.11.02.06. If the home does not actually meet the current energy code, that marketing language becomes a liability.

## What Brokers Need to Audit and Enforce

Supervising brokers in Maryland carry independent liability under Business Occupations and Professions Article Section 17-322.1 for the acts of their associated licensees. This is not a passive obligation. MREC expects brokers to maintain systems that catch compliance gaps before they become complaints.

**Brokers should audit three specific areas in every transaction file involving new construction or renovated properties.** First, verify that the listing agent documented permit research—either through a county permit search printout or written confirmation from the seller. Second, confirm that the disclosure form (10-702) addresses any known code-related conditions rather than relying solely on a blanket disclaimer. Third, ensure that any marketing claims about energy efficiency or code compliance are substantiated with documentation in the file.

| Audit Checkpoint | What to Look For | Frequency |
|-----------------|------------------|-----------|
| Permit history documentation | County search printout or seller attestation | Every listing involving renovations |
| 10-702 form completeness | Code-related questions answered, not blank | Every residential transaction |
| Marketing compliance | Energy/green claims matched to documentation | Every listing with efficiency claims |
| Inspection response tracking | Code violation cures documented with permits | Every transaction with inspection findings |
| Jurisdiction-specific code review | Local amendments identified for property's county | Every transaction crossing county lines |

Brokers operating teams across multiple Maryland jurisdictions face particular exposure. A team leader in Prince George's County whose agents also list in Charles County must ensure those agents understand the differing local amendments. MREC has [disciplined brokers](https://www.dllr.state.md.us/license/mrec/) specifically for inadequate supervision when agents misrepresented code compliance status in multiple transactions.

## Liability Exposure: What Happens When Agents Get This Wrong

The consequences of ignoring Maryland building code updates 2026 fall into three categories: regulatory discipline, civil liability, and transactional fallout. Regulatory discipline from MREC can include fines up to $5,000 per violation, license suspension, or revocation under Section 17-322. Civil liability opens the agent and brokerage to lawsuits from buyers who discover undisclosed code violations post-closing—damages that E&O insurance may not fully cover if the carrier determines the agent's failure was intentional or reckless.

Transactional fallout is the most immediate risk. A buyer who discovers unpermitted work during the inspection period will either demand repairs, request a price reduction, or walk away entirely. If the buyer's lender requires code compliance documentation that the seller cannot produce, the loan falls through. The listing agent's commission evaporates, and the seller may blame the agent for not identifying the issue before listing.

> Under Maryland Real Property Article Section 10-702(d), a seller who provides a disclaimer statement rather than a disclosure is not relieved of liability for fraudulent misrepresentation or concealment. Similarly, an agent's knowledge of code violations is not extinguished by the seller's choice to disclaim.

## Practical Steps for Staying Compliant Through Q3 and Q4 2026

Start by downloading the current Maryland Codes Administration implementation bulletin, which specifies effective dates for each code section and identifies transitional provisions for projects already under permit. Bookmark your county's permit search portal—most Maryland counties offer free online searches by address. Make it a standard step in your listing presentation to run a permit search before signing the listing agreement.

Build a clause into your listing intake process that asks sellers directly: "Have you completed any additions, structural modifications, or system replacements without a building permit?" Document their answer in writing. If they answer yes, discuss the disclosure implications before the property goes active. This protects you and gives the seller an opportunity to cure or disclose before buyers get involved.

For buyer-side agents, the building code updates mean sharpening your inspection contingency strategy. When representing buyers purchasing homes built or renovated after January 2026, request the Certificate of Occupancy and final inspection report as part of your initial document request. Do not wait for the inspection period to discover that a builder never obtained final approval.
